# 매크로 한눈에 보기

금 선물(GCZ6), WTI 원유 선물, 미국 3년물·10년물 국채 금리, S&P 500, 나스닥, 그리고 변동성·심리 지표(VIX, MOVE, VKOSPI, 공포·탐욕 지수)를 하루(1D) 기준으로 한 페이지에서 보는 대시보드입니다.

화면은 두 탭으로 나뉩니다.
- **시장 흐름** : 맨 위에 그날의 한 줄 요약, 그 아래 차트
- **경제 일정** : 한국·미국 기준금리 결정, CPI(전체·근원·에너지), PCE(물가·소득·지출), 고용(일자리·실업률·시급), 미국 소매판매·GDP 발표의 일정·예상·결과. 물가는 전년비·전월비를 함께 보여 줌 (주소 끝에 `#calendar`를 붙이면 바로 열림)
  - 맨 위 **지표 점검**에서 세 가지 질문과 보고서별 질문에 규칙으로 답하고, 일정마다 '확인 결과 보기'로 네 가지 점검 결과를 볼 수 있어요.

## 구성
- `index.html` : 화면 (GitHub Pages)
- `scripts/fetch_data.py` : 시세 받기 (Yahoo Finance, 미국 재무부/FRED, CBOE, 한국거래소 Open API, CNN). 달러 인덱스(`dxy`)는 차트 없이 '시장 반응' 점검에만 씀
- `scripts/update_calendar.py` : 경제 일정의 결과·이전 값 채우기 (FRED, 한국은행 ECOS)
- `.github/workflows/update-data.yml` : 자동 실행 (한국 시간 화~토 오전 7시 30분, 월~금 오전 9시 30분)
- `data/market.json` : 받아 온 시세 (자동 생성)
- `data/calendar.json` : 경제 일정 (일정·예상은 손으로, 결과는 자동)

## 자동 업데이트 일정
GitHub Actions가 아래 시간에 자동으로 실행돼요. (`.github/workflows/update-data.yml`)

| 한국 시간 | 요일 | 하는 일 |
| --- | --- | --- |
| 오전 7:30 | 화~토 | 전날 미국 장 마감 시세 (주가·금리·금·원유·VIX·MOVE·공포탐욕), VKOSPI, 미국 경제지표 결과 |
| 오전 9:30 | 월~금 | 시세 다시 받기 + 그날 오전 8시에 나온 한국 물가·고용 결과 |

- 미국 지표(CPI·고용 21:30/22:30, FOMC 새벽 3~4시)는 **다음 날 오전 7:30** 실행에 들어와요.
- 한국 물가·고용(오전 8시)은 **같은 날 오전 9:30**, 한국은행 기준금리(오전 10시쯤)는 **다음 날 오전 7:30** 실행에 들어와요.
- GitHub 예약 실행은 몇 분~수십 분 늦게 시작될 수 있어요. 급하면 Actions 탭 → 시세 데이터 업데이트 → **Run workflow**.
- 화면 위쪽 '마지막 데이터 갱신' 옆에 다음 예정 시각이 나와요. 실행 시간을 바꾸면 `index.html`의 `RUNS_KST`도 같이 고쳐 주세요.

## 오늘의 한 줄 요약 읽는 법
가장 최근 미국 장 마감일의 움직임을 전날과 비교해 규칙으로 한 문장을 만듭니다. (AI가 쓰는 글이 아니라, 같은 숫자면 늘 같은 문장이 나옵니다.)
- '움직였다'고 보는 기준: 유가 ±1.5%, 금 ±1%, 10년물 ±4bp, 주가 ±0.5%
- 유가·금 동반 상승 → **불안 장세** / 금리↑·주식↓ → **금리 부담 장세** / 금리↓·주식↓ → **경기 걱정 장세**
- 금리↓·주식↑ → **안도 장세** / 금리↑·주식↑ → **자신감 장세** / 그 밖에 주식 강세·약세, 금리 상승·하락, 관망
- '최근 5거래일 한 줄 요약'을 펼치면 날짜별 요약이 나옵니다.
- 기준값은 `index.html`의 `readDay` 함수에서 바꿀 수 있습니다.

## 지표 점검 읽는 법 (경제 일정 탭)
가장 최근에 나온 미국 지표를 규칙으로 읽어 답합니다. (AI가 쓰는 글이 아니라, 같은 숫자면 늘 같은 답이 나옵니다.) 기준값은 `index.html`의 `CHECK`에서 바꿀 수 있어요.

**세 가지 질문**
- 일자리는 유지되고 있는가? → 최근 3개월 일자리 평균(수정치 반영)이 5만 명 이상이고 실업률이 3개월 새 0.2%p 넘게 오르지 않았으면 '유지'
- 물가 상승 압력은 약해지고 있는가? → 최신 CPI·PCE의 전체·근원 전년비 4개 중 절반 넘게 내려가면 '약해짐', 절반 넘게 오르면 '커짐'
- 소비자는 지출을 이어가고 있는가? → 소매판매 통제그룹·개인지출·GDP 실질 소비가 모두 플러스면 '이어감'

**보고서별 질문**
- 고용보고서: 일자리와 임금이 소비를 뒷받침하는가? → 일자리 3개월 평균 + 시급 전년비와 직전 CPI 비교(실질 임금)
- CPI: 물가 둔화가 여러 항목에서 나타나는가? → 전체·근원·에너지 전년비가 지난달보다 내려간 항목 수
- 소매판매: 소비가 얼마나 유지되고, 어떤 항목이 변화를 이끌었나? → 통제그룹 크기 + 항목별 기여도(자동차·주유소·건축자재·외식·그 밖)
- GDP와 PCE: 성장·소득·소비·물가가 앞서 본 흐름과 일치하는가? → 같은 달의 CPI↔PCE 물가, 소매판매↔개인지출, 일자리↔개인소득, GDP↔소비 방향 비교

**네 가지 점검** (보고서 카드와 일정마다 '확인 결과 보기')
- 예상치와 실제치: 예상이 있는 항목마다 강함·약함(물가는 높음·낮음). 실업률은 낮을수록 '강함'
- 이전 수치와 수정치: 지난 1~2개월 수정 내역과, 수정치를 반영한 지난번 → 이번 흐름
- 세부 항목: 전체(첫 항목)와 내부 항목(근원·에너지, 실업률·시급, 통제그룹 등)이 같은 쪽으로 움직였는지
- 시장 반응: 발표 날 미국 장 마감 기준 3년물·10년물 금리(±3bp), 달러 인덱스(±0.2%), S&P 500(±0.3%). 금리가 오르면 '강한 지표(물가는 부담)'로 읽은 것으로 봐요. 하루 종가라 같은 날 다른 뉴스도 섞여 있어요.

## 경제 일정 관리하기 (`data/calendar.json`)
- 일정 하나는 `events` 안의 한 칸입니다. 시간은 모두 **한국 시간** (`release_kst`).
- 값은 지표마다 `forecast`(예상) · `actual`(결과) · `previous`(이전)이 있습니다.
  - **예상**은 손으로 넣습니다. 미국 지표는 발표 주에 Forex Factory 예상치로 빈칸을 자동으로 채우려고 시도합니다.
  - **결과**는 발표 30분 뒤부터 자동으로 채웁니다. 미국은 FRED, 한국은 한국은행 ECOS(인증키 필요).
  - 결과가 들어오면 같은 지표의 다음 일정 **이전** 칸도 채웁니다.
  - 손으로 넣은 값은 자동 갱신이 덮어쓰지 않습니다. 고치고 싶으면 그 칸을 직접 수정하세요.
- 단위: 금리·물가·실업률은 %, 일자리·취업자 증감은 **만 명** (미국 비농업 15만 명 → `15.0`). 미국 기준금리는 범위의 **상단**만 적습니다 (3.75~4.00% → `4.0`).
- GDP는 `period`를 분기(`2026-Q3`)로, `estimate`에 `속보치`·`잠정치`·`확정치`를 적습니다. 잠정치·확정치의 '이전'은 같은 분기의 앞선 추정치예요.
- `revisions` : 그 발표에서 바뀐 지난달 값 `[{"period": "2026-09", "key": "nfp", "from": 2.9, "to": 6.0}]`. 미국 고용·소매·PCE는 발표 뒤 10일 안에 자동으로 채우고, 손으로 넣어도 됩니다. 빈 목록 `[]`은 '수정 없음'.
- `drivers` : 소매판매 항목별 기여도(%p). 자동으로 채움.
- 날짜가 공식 발표 전 추정이면 `"tentative": true` → 화면에 '날짜 잠정' 표시.
- 새 일정은 같은 지표의 기존 칸을 복사해 `id`, `release_kst`, `period`(기준월 `YYYY-MM`)만 바꾸면 됩니다.
  - 미국: [Fed FOMC 일정](https://www.federalreserve.gov/monetarypolicy/fomccalendars.htm), [BLS 일정](https://www.bls.gov/schedule/), [BEA 일정](https://www.bea.gov/news/schedule)
  - 한국: [한국은행 금통위 일정](https://www.bok.or.kr), [국가데이터처 공표 일정](https://mods.go.kr)
- 자동으로 채워지는 결과는 최신 수정치 기준이라, 첫 발표 숫자와 조금 다를 수 있습니다 (특히 미국 고용).
  - 미국 소매판매 일정: [인구조사국 발표 일정](https://www.census.gov/retail/sales.html)

## 변동성·심리 지표 읽는 법
- **VIX** : 평상시 12~20, 30 이상이면 경계 표시
- **MOVE** : 미국 국채 변동성. VIX와 함께 보면
  - VIX 낮고 MOVE만 높다 = 주식은 낙관, 채권은 불안
  - VIX 높고 MOVE만 낮다 = 주식은 불안, 채권은 안정
  - 둘 다 높다 = 시장 전체 변동성 확대 (같이 출렁임)
  - 둘 다 낮다 = 시장 전체 안정 (같이 잠잠)
  - '높음' 기준은 VIX 20, MOVE 100 (`index.html`의 `MATRIX_TH`에서 바꿀 수 있음)
- **VKOSPI** : 평상시 20 안팎, 40 이상이면 경계 표시
- **공포·탐욕 지수** : [CNN Fear & Greed](https://edition.cnn.com/markets/fear-and-greed) 화면과 같은 값을 씁니다.
  - 구간: 0~24 극단적 공포, 25~44 공포, 45~55 중립, 56~75 탐욕, 76~100 극단적 탐욕
  - 지금 · 전일 종가 · 1주 전 · 1달 전 · 1년 전 값은 CNN이 발표한 숫자를 그대로 보여 줍니다.
  - '세부 지표 7개 보기'를 누르면 CNN이 지수를 만드는 7가지 지표(시장 모멘텀, 주가 강도, 주가 폭, 풋·콜 옵션, 시장 변동성, 안전자산 수요, 정크본드 수요)의 점수가 나옵니다.

## 경제 일정 자동화 (2026-11 추가)

기존 `scripts/update_calendar.py`(FRED/ECOS 실제치, 이전치, 수정치)는 유지합니다.
새 자동화는 매번 다음 순서로 실행됩니다.

1. `scripts/update_schedule.py`: **공식적으로 날짜·시간을 확인할 수 있는** 미국 CPI/고용(BLS ICS), 미국 PCE/GDP(BEA ICS), 미국 FOMC(Federal Reserve 회의 일정)를 수집합니다. 이미 존재하는 일정과 일치시키고 새 일정만 추가하며 변경된 발표 시각은 `data/schedule_history.json`에 기록합니다. 데이터 발표가 이미 지난 일정은 임의로 바꾸지 않습니다. 시차는 `America/New_York` → `Asia/Seoul`로 변환하여 서머타임을 자동 반영합니다.
2. `scripts/update_calendar.py`: 기존 실제치·이전치·수정치 수집에 이어 이번 주 Forex Factory 예상치를 확인합니다. **이전에 Forex Factory에서 자동 채운 예상치만** 발표 전 갱신하며, 기존 수동 예상치는 덮어쓰지 않습니다. 예상치가 변할 때마다 `data/forecast_history.json`에 저장합니다. 새로 자동 채운 값에는 `forecast_source`와 `forecast_as_of`가 붙습니다.
3. `scripts/validate_calendar.py`: 날짜, 지표, 수치 및 중복 ID를 검증하고 누락된 발표 결과·미래 일정 부족은 경고로 출력하며 `data/calendar_health.json`에 점검 결과를 남깁니다.

### 운영상 중요한 제한

- **한국 CPI/고용/금통위, 미국 소매판매 발표 일정은 이번 버전에서 신규 자동 생성하지 않습니다.** 안정적으로 파싱 가능한 공식 발표 일정 인터페이스를 검증하기 전에는 추정 날짜를 생성하지 않고 기존 수동 일정을 보존합니다. `calendar_health.json`의 35일 이상 미래 일정 부족 경고를 확인하세요.
- 시장 예상치는 통계기관의 공식 발표치가 아닙니다. 현재 Forex Factory 주간 JSON을 사용하는 기존 코드를 유지하되, 제공처의 접근 정책 및 재사용 허용 범위를 확인하고 운영해야 합니다. API 실패 시 이전 값을 최신값처럼 갱신하지 않습니다.
- 공식 사이트의 일정 형식이 바뀌거나 접속이 차단될 수 있습니다. 세 공식 소스 중 **모두** 실패해도 기존 일정과 시세·발표치 자동화는 계속 실행합니다. 실패는 로그에 경고하며 확인된 날짜가 없으면 새 일정을 만들지 않습니다.
- GitHub Actions를 처음 사용할 때 `Settings → Secrets and variables → Actions`에 기존 `ECOS_API_KEY`와 `KRX_API_KEY`를 필요한 경우 등록하세요. 새 일정 수집용 추가 키는 없습니다.
- `schedule_history.json`, `forecast_history.json`은 append-only 기록입니다. 불필요한 대량 증가가 생기면 기간별 아카이브로 분리하세요.
- 로컬 검증: `pip install requests beautifulsoup4`, `python -m unittest discover -s tests -v`, `python scripts/validate_calendar.py`.
